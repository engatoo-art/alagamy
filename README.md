# العجمي للخضروات والفاكهة — برنامج الحسابات

برنامج ويب لمحل خضار وفاكهة بالجملة، بيشتغل من أي كمبيوتر أو موبايل.

## اللي فيه
- **البيع**: بالكيلو أو بالعدد، نقدي أو آجل، مع رهن الصناديق، وطباعة إيصال 80mm أو فاتورة A4
- **حسابات الزباين**: كشف حساب بالتفصيل، تحصيل دفعات، مرتجع صناديق (يتخصم من الحساب أو يترد نقدي من العهدة)
- **الموردين والنقلات**: تسجيل النقلة بالأصناف والعدد، ومتابعة اللي اتباع والباقي
- **تصفية المورد**: فاتورة بأسعار البيع الفعلية والوزن الكلي، وخصم العمولة والنولون والعتالة، وبعدين موافقة المدير ثم الصرف من العهدة
- **العهدة اليومية**: كل فلوس داخلة وخارجة، ووارد ومصروفات يدوي، ورصيد أول وآخر اليوم
- **الموافقات**: فواتير الآجل وطلبات الآجل للزباين والتصفيات قبل الصرف
- **التقارير**: يومي وشهري وفترة، والمديونيات والصناديق
- **المستخدمين والصلاحيات**: المدير بيفعّل الحسابات ويحدد صلاحيات كل محاسب
- **نسخة احتياطية Excel** فيها كل البيانات

## التركيب (مرة واحدة)
1. **Supabase** (قاعدة البيانات، مجانية): اعمل مشروع جديد، وافتح SQL Editor، والصق محتوى `supabase/schema.sql` ودوس Run.
   - من Authentication ← Sign In / Providers ← Email: اقفل **Confirm email**.
   - من Project Settings ← API: انسخ Project URL ومفتاح anon public، وحطهم في `docs/js/config.js`.
2. **GitHub Pages**: من Settings ← Pages اختار Deploy from a branch ← main ← /docs.
3. افتح الرابط، واعمل أول حساب. **أول حساب بيبقى هو المدير تلقائيًا.**

## للمطورين
- `supabase/schema.sql`: كل الجداول والدوال والصلاحيات. آمن تشغيله أكتر من مرة.
- `docs/`: الواجهة (HTML/CSS/JS من غير build).
- `dev/`: تجربة محلية على Postgres (`test_flows.py` بيختبر كل العمليات، و`server.mjs` سيرفر تجربة).
