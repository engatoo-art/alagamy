# تسطيب برنامج العجمي على الاستضافة (cPanel)

البرنامج هنا شغال بالكامل على الاستضافة بتاعتك (PHP + MySQL) — من غير Supabase ومن غير GitHub.

## قبل ما تبدأ: خد نسخة كاملة من البرنامج القديم
1. شغّل آخر `schema.sql` في Supabase (علشان النسخة تطلع فيها الصلاحيات وتفاصيل فواتير العملاء).
2. من البرنامج القديم: **الإعدادات ← النسخة الاحتياطية ← نزّل النسخة الكاملة** (ملف JSON).
3. من اللحظة دي متسجلش أي حاجة في البرنامج القديم لحد ما النقل يخلص.

## الخطوات على cPanel
1. **نسخة PHP:** cPanel ← Select PHP Version ← اختار **8.1 أو أحدث** (8.2 أحسن).
2. **قاعدة البيانات:** cPanel ← MySQL Databases:
   - اعمل قاعدة بيانات جديدة (مثلاً `alagamy`).
   - اعمل مستخدم جديد بكلمة سر قوية.
   - ضيف المستخدم على قاعدة البيانات واختار **ALL PRIVILEGES**.
   - اكتب عندك: اسم قاعدة البيانات واسم المستخدم كاملين (بيبقى قبلهم اسم حسابك، مثلاً `ahmed_alagamy`) وكلمة السر.
3. **شهادة الأمان SSL:** cPanel ← SSL/TLS Status ← اتأكد إن الدومين عليه علامة خضرا (AutoSSL مجاني). البرنامج بيحوّل أي دخول لـ https.
4. **رفع البرنامج:** cPanel ← File Manager ← `public_html` ← Upload ← ارفع `Alagamy-hosting.zip` ← اضغط عليه يمين ← **Extract**.
   - لو مش شايف ملف `.htaccess`: Settings ← Show Hidden Files.
5. **التسطيب:** افتح `https://الدومين-بتاعك/api/install.php` واملا:
   - بيانات قاعدة البيانات من خطوة 2 (السيرفر غالباً `localhost`).
   - حساب المدير: **نفس اسم الدخول القديم** لو هتنقل بيانات (علشان الفواتير القديمة تفضل باسمك)، وكلمة سر جديدة.
   - ملف النسخة الكاملة (JSON) من الخطوة الأولى.
6. **امسح `api/install.php`** من File Manager بعد ما يقولك "التسطيب خلص بنجاح".
7. ادخل البرنامج بحساب المدير ← **الإعدادات ← المستخدمين** ← اعمل لكل محاسب كلمة سر جديدة (كلمات السر القديمة مش بتتنقل) وابعتهاله واتساب من نفس الشاشة.

## النسخ الاحتياطي
- cPanel ← **Backup** ← نزّل نسخة من قاعدة البيانات كل أسبوع.
- ومن البرنامج نفسه: **نزّل النسخة الكاملة** وملفات Excel (وبرنامج الويندوز بيحفظ Excel لوحده كل يوم).

## الحماية
- كلمات السر متشفرة (bcrypt)، والدخول بيتقفل ربع ساعة بعد 10 محاولات غلط.
- ملفات البرنامج الداخلية وإعدادات قاعدة البيانات مقفولة قدام المتصفح.
- كل عملية بتتأكد من صلاحية الحساب قبل ما تتنفذ، وأي حذف أو تعديل مهم بيحتاج موافقة المدير.
